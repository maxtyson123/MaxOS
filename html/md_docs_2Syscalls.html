In the future there will be a syscall abstraction method allowing to switch out the syscall implementation for different platforms. Ie a program could load linux vX if it supports it, or windows vX if it supports it. This will allow for versions such as MaxOSvX. This will be done via a translation layer to convert it into the correct syscall for the platform.

This is helpful for updating syscall table (I don't know if that will even happen, or it will just grow) because it can be designed in a way the previous version can be translated into the latest. This may be bad but dk yet. Ie Linux v2 could target MaxosV2 but then would have to be translated to MaxOsV3.
